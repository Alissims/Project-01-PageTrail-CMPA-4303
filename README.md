# Project-01-PageTrail-CMPA-4303
PageTrail
What is this?

PageTrail is a little web app I built to keep track of my reading. It has three shelves: books I want to read, the one I'm currently working through, and books I've finished (with a rating). You type in a book by hand, move it between shelves as you progress, and give it a rating when you're done. No accounts, no syncing everything lives in your browser's localStorage, so it's still there when you come back.

Why does it exist?

Honestly, I got tired of the two options that seemed to exist for tracking what I read: Goodreads, which slowly turns your reading into a social performance, or a $5/month app with features I'll never use. I just wanted a quiet, private shelf of my own. On top of that, I wanted a project that pushed me to use an external API and localStorage for the first time  both were new territory.

Scope

Project 01 (this version): Add books manually, sort by status, rate finished books. All data stays in the browser.
Project 02 (up next): Hook up the Google Books API to auto-fill covers, authors, and page counts. Add search/filtering and a small stats page.
